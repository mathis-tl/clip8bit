# Style « doodle » : recette complète (clip10 Tiakola « Bottega », 3 nov. 2026)

Un extrait de clip, **image d'origine plein cadre 1080×1920, audio d'origine**, par-dessus : sous-titres **gribouillés au feutre rouge** qui s'écrivent mot à mot, petits dessins (couronne, « !! », éclair qui sort du cadre, soulignements), **écho** sur quelques mouvements forts, étalonnage renforcé pour la compression TikTok. Pas de pixel, pas de peinture, pas d'IA, 100 % gratuit, tout en local. Inspiration : Tiakola « AF1 Nouvo » (YouTube `4u1xsdmIm6A`, 40–50 s). Référence validée (5 nov. 2026) : `sorties/finaux/clip10_tiakola_bottega_v4_vertical_doodle-rouge.mp4` (config `exemples/config_doodle_bottega_rouge_boost.json`) ; anciennes versions v1–v3 ; `sorties/finaux/clip10_tiakola_bottega_v1_vertical_doodle-rouge.mp4` ; essais `doodle_lacrim_v3.mp4`, `doodle_sch_v1.mp4` (dans `sorties/essais/`).

## Choix validés par l'auteur
- Image : vidéo d'origine, recadrée serré sur le sujet, sans transformation (le style « dessin/aplats/peinture » de `dessin.py` n'est PAS utilisé ici).
- Texte : **rouge `#FF2D0A`** (bleus et jaunes testés, moins lisibles sur les plans sombres) ; police **Sedgwick Ave Display** (`polices/`), un peu de **Kristi** (15 % des bulles) ; feutre « plein » étiré en hauteur ×1,4.
- Hook : **mot-choc géant** (nom de l'artiste, 330 px, penché) + « !! » + éclair hors cadre dans la 1re seconde. Le hook « tour de visage » est abandonné.
- **Standard « boost TikTok » (validé par l'auteur le 05/11/2026, à reprendre pour tout nouveau clip doodle)** : rouge `#FF1A00`, `nettete` 0,42, `etalonnage` `{expo: -0,12, sat: 1,34, eclat: 0,26, nettete: 0,5}` (avant : `#FF2D0A`, 0,3, sat 1,22, éclat 0,22, netteté 0,35). Raison : TikTok recompresse et ternit le rouge fin, adoucit les détails. Vérifié sur 8 images v3/v4 : rouge plus saturé, détails plus nets, ni halo ni grain ; **non vérifié** après vraie compression TikTok ni sur tout le clip. Ce sont des clés de config (les défauts du moteur ne changent pas, les clips validés restent reproductibles) : partir de `config_doodle_bottega_rouge_boost.json`, pas de `config_doodle_bottega_rouge.json` (v3).
- Pas d'étoiles. Une seule couleur par vidéo (la couleur par artiste n'a pas été essayée).
- Prendre **le moment fort du morceau** (refrain, couplet le plus marquant), pas le début.

## Chaîne de fabrication (dépôt `<racine du dépôt>`)
1. **Extrait** : `python3 scripts/clip2/fetch.py <url YouTube> <début m:ss> <fin m:ss> work/<slug>` → `work/<slug>/clip.mp4` (25 i/s), `audio16k.wav`. 45 s utilisés (30 s possible).
2. **Bandes noires** : `ffmpeg -i work/<slug>/clip.mp4 -vf cropdetect=24:2:0 -t 20 -f null -` → lignes utiles `rows`. Fenêtre de recadrage `crop_w × crop_h` au format 9:16 : 1080 de haut → 608×1080 (source 16:9 sans bandes, le plus net) ; 960 de haut (bandes fines) → 540×960 ; 800 de haut (bandes épaisses, ex. Lacrim) → 450×800 (plus doux, agrandi 2,4×).
3. **Paroles + temps** : `mlx_whisper work/<slug>/audio16k.wav --model mlx-community/whisper-large-v3-mlx --language fr --word-timestamps True --output-format json --output-name w_large --output-dir work/<slug>` ; `python3 scripts/clip2/lyrics.py "<artiste titre>" work/<slug>/lyrics_full.txt` (Genius, cookies dans `~/.config/clip-8bit/genius_cookies.txt`, hors dépôt ; si la recherche échoue, essayer l'URL `https://genius.com/<artiste>-<titre>-lyrics`). Garder dans `lyrics.txt` seulement les couplets de l'extrait, `cp w_large.json whisper.json`, puis `python3 scripts/clip2/align2.py work/<slug> 45` → `subs.json` (vers + temps de chaque mot). **Contrôle** : second passage `--model mlx-community/whisper-small-mlx` ; les lignes dont les deux modèles divergent de plus de 0,15 s sont douteuses. Sur les raps rapides, Whisper retrouve parfois 40 % des mots seulement : les temps sont alors interpolés → écouter.
4. **Habillage des vers** (copie de `subs.json` dans `exemples/subs_doodle_<slug>.json`) : ajouter par vers `souligne` (indice du mot), `eclair: true`, `fleche: [dx,dy]`, `tampons: [{"type": "couronne|exclam|exclam2|eclair|fleche", "mot": indice}]`, `kristi: [indices]` (la bulle contenant ce mot passe en Kristi). Règle : un tampon sur un mot fort (nom propre, mot de punchline), pas plus d'un par vers.
5. **Config** (`exemples/config_doodle_<slug>.json`, modèle : `config_doodle_bottega_rouge_boost.json`, valeurs « boost TikTok » ci-dessus) :
   `rows, crop_w, crop_h, cx:"auto", styles:["brut"], subs, taille:190, police, police2, p_kristi:.15, etire_v:1.4, etire_v2:1.6, trace:"plein", max_mots:4, angle_max:7, vit_max:2.6, echo_pct:.12, echo_dur_s:.5, nettete:.42, etalonnage:{expo:-.12, sat:1.34, eclat:.26, nettete:.5}, hook:"mot", hook_mot:"<ARTISTE>", couleur:"#FF1A00", graine`.
6. **Découpe des plans** : `python3 scripts/clip2/doodle_clip.py scan work/<slug> "[y0,y1]"` → liste des coupes + `coupes.png` + `cx_auto.json` (centre de cadrage automatique par plan, sur l'énergie de contours).
7. **Rendu** : essai `python3 scripts/clip2/doodle_clip.py rendre work/<slug> exemples/config_….json sorties/essais/doodle_<slug>_vN.mp4` ; test court `--de 0 --a 12` ; final `--max` (x264 veryslow crf 14, AAC 320k, ≈ 100 Mo pour 45 s, ~8 min). Un `.rapport.json` est écrit à côté (bulles, plages d'écho, coupes). **Ne jamais lancer deux rendus vers le même fichier.**
8. **Couvertures** : `python3 scripts/clip2/doodle_cover.py work/<slug> exemples/config_….json sorties/essais/couvertures_<slug> clipN "TITRE|ARTISTE" A:<s>,B:<s>,C:<s>` (3 images de la source à choisir sur une planche : visage lisible, bouche ouverte ou expressive, hors flou de mouvement ; titre gribouillé dans la zone sûre du profil, couronne, « !! », éclair).
9. **Contrôles** : décodage `ffmpeg -v error -i f.mp4 -f null -` ; planche d'images toutes les 2,5 s (`-vf fps=1/2.5,scale=216:384,tile=9x2`), relire texte coupé, lisibilité, écho ; pour les temps des sous-titres vs `subs.json`, détection des pixels rouges (R>170, G<90, B<100) dans la zone de chaque bulle. **Non contrôlable par le script** : justesse des temps face au son, mouvement en lecture, ton.
10. **Livraison** : `sorties/finaux/clipN_<artiste>_<titre>_v1_vertical_doodle-<couleur>.mp4`, couvertures dans `sorties/finaux/couvertures/`, commit `git add scripts exemples polices RECETTE.md DOODLE.md` (jamais `.claude/`). Les MP4 sont ignorés par git : à sauvegarder.

## Zones TikTok : OBLIGATOIRE (ajouté le 04/11/2026, `scripts/clip2/zones.py`)
l'auteur a constaté que les écritures passaient sous l'interface TikTok (haut / île dynamique, icônes j'aime-commentaires-partage à droite, description en bas). Désormais :
- **Zone sûre du texte : x 60 → 910 (jusqu'à 1020 si la boîte est entièrement au-dessus de y = 780), y 240 → 1290.** Rouge toujours recouvert : y < 230 ; x ≥ 920 pour 800 ≤ y ≤ 1640 ; x < 45 et x > 1035 ; y > 1630. Orange : promotion suggérée dès y = 1300. Calibrage du 21/10/2026.
- `doodle_clip.py` place chaque bulle et chaque dessin dans cette zone et **fait échouer le rendu** (`ZONES TIKTOK : n débordement(s)`) si un texte ou un dessin en sort ; `"zones_off": true` pour passer outre (à éviter). Le hook « visage » (abandonné) n'y tient pas toujours.
- Dessins : positions candidates autour des mots (voir « Chevauchements ») ; l'éclair à moitié hors cadre est **toujours à gauche** (rien n'y est recouvert). L'éclair et la flèche d'un vers (`eclair: true`, `fleche`) sont aussi contrôlés dans la zone sûre.
- Réglages : `seuil_zone` (1,6 par défaut, tolérance de « zone calme » : la zone sûre recouvre le visage, sinon les grandes tailles disparaissent), `poids_visage` (1,0).
- **Contrôle systématique avant de livrer** : `python3 scripts/clip2/zones.py planche <video.mp4> <planche.png> 12` (rouge = recouvert, orange = promotion, cadre vert = zone sûre), relue image par image. Non vérifié par la machine : l'interface réelle varie selon le téléphone (barre d'onglets, légende longue sur 3 lignes).
- Couvertures : la grille du profil recadre en 3:4 (y 240 → 1680), la règle ci-dessus ne s'y applique pas.

## Chevauchements : JAMAIS (règle permanente, ajoutée le 04/11/2026, `scripts/clip2/chevauche.py`)
Deux éléments ne se recouvrent jamais **pendant qu'ils sont tous deux à l'écran** : bulle de texte, soulignement, éclair/flèche d'un vers, tampon (couronne, « ! », étoile, flèche, éclair), hook, doodle libre. Sur Bottega v2 : 18 couples en conflit (+ 4 éclairs de vers hors zone sûre) ; sur SCH : 4.
- **Mesure** : chaque élément = masque d'encre réduit ×4 et dilaté de ≈ 8 px de chaque côté (marge de sécurité) + intervalle d'affichage [début de tracé, `fin` + 0,18 s d'effacement]. Conflit si les intervalles se recouvrent de plus de 0,02 s **et** si la surface commune des masques dépasse **5 % du plus petit des deux** (`TOL`). Le placement vise 2 % (`TOL_PLACEMENT`) pour absorber l'arrondi de la grille ×4. Les boîtes englobantes sont dans le rapport, à titre indicatif (les masques sont plus justes que des rectangles pour un texte penché de ±7°).
- **Placement** (`placer`, `tampons_bulle`) : la bulle est testée sur une grille plus fine (pas de 45 px, 5 abscisses) contre tout ce qui est à l'écran en même temps (pas seulement la bulle précédente). Pour un vers à éclair, deux variantes (éclair à droite / à gauche). Les dessins sont cherchés sur les meilleures positions du texte : haut centre/gauche/droite, bas, côtés, puis taille ×0,8 et ×0,62, sinon supprimés (message `dessin supprimé`) ; chaque repli coûte au score, donc une taille de texte plus petite est préférée à un dessin sacrifié. L'éclair géant reste à gauche et glisse en hauteur. Si rien n'est libre, un élément déjà à l'écran peut être **écourté** (sa fin avancée jusqu'à l'apparition de la nouvelle bulle) tant qu'il reste entièrement tracé (`penalite_ec`) : dessins et hook d'abord, texte en dernier recours.
- Durées inchangées (un dessin reste ≈ 1,3 s après son tracé, jusqu'à `fin de la bulle + 0,3 s` au moins) : ses positions sont testées sur toute cette durée, donc il peut rester pendant la bulle suivante sans la toucher.
- **Le rendu échoue** (`CHEVAUCHEMENTS : n couple(s)…`) s'il en reste un ; `"chevauchement_off": true` pour passer outre (à éviter). `"evitement": false` restaure l'ancien placement (reproduire un clip validé avant le 04/11, p. ex. Bottega v2) : le contrôle reste actif, il faut alors `chevauchement_off` pour rendre.
- **Mesurer sans rendre** (≈ 15 s) : `python3 scripts/clip2/doodle_clip.py mesurer work/<slug> <config> <prefixe>` → liste des couples avec leurs temps, `<prefixe>.rapport.json` (tous les éléments avec intervalle et boîte). `python3 scripts/clip2/chevauche.py <rapport.json>` le relit. Tests : `python3 scripts/clip2/test_chevauche.py`.
- Contrôle visuel avant de livrer : planche d'images aux instants où plusieurs éléments coexistent (`ffmpeg -ss t -frames:v 1`, relue image par image) + `zones.py planche`. Non contrôlable par la machine : le mouvement en lecture (le trait « bout » : un masque statique ne le voit pas, d'où la marge de 8 px) et la lisibilité sur téléphone.

## Règles de mise en page (codées dans `doodle_clip.py`)
- **Moins d'écriture** : chaque vers est coupé en bulles de **4 mots maximum** (de préférence après une virgule). **Une seule bulle à l'écran** : elle s'efface quand la suivante commence.
- **Taille et place variables** : 3 tailles (190 / 148 / 110 px). Pour chaque bulle, on essaie la plus grande taille ; elle est posée sur la zone la plus **calme** de l'image (peu de contours, moyenne sur la durée de la bulle), jamais sur la zone du visage, loin de la bulle précédente ; une bulle < 0,9 s n'est jamais en grande taille ; pas plus de 2 petites de suite. Le texte reste entièrement dans l'écran (largeur et hauteur).
- **Texte penché** : ±3° à ±7° (signe aléatoire, graine fixée).
- **Vitesse d'écriture** : `vit = 0,5 s / (temps disponible après le dernier mot)`, bornée entre 1 et 2,6. Chanteur rapide → la bulle s'écrit plus vite et la phrase est toujours finie avant la suivante.
- **Tampons** : couronne au-dessus de la bulle ; « !/!! » à côté ; grand éclair (300 px) collé au bord, **à moitié hors cadre** ; flèche courbe à côté du texte.
- **Écho** : l'image courante + copies de 3, 6, 9, 12 images plus tôt (poids .8/.6/.45/.3), chacune zoomée de +3,5 % par pas → traînée visible même quand rien ne bouge. **Un par plan au plus, jamais sur deux plans consécutifs, ≥ 3 s d'écart, entièrement dans un seul plan** (début ≥ coupe + 8 images, fin ≤ coupe suivante − 3 images ; durée réduite dans les plans courts, ≥ 8 images), choisi sur le mouvement le plus fort, budget `echo_pct` = 12 % des images (réel : 3 à 8 %). L'historique de copies est vidé à chaque coupe.
- **Étalonnage** (`etalonner`) appliqué à l'image seulement, pas au texte : exposition −0,12 diaphragme, saturation, éclat (clarté locale + S léger), netteté en plus de celle qui compense l'agrandissement. Valeurs du **standard « boost TikTok »** (config `…_boost.json`) : saturation ×1,34, éclat 0,26, netteté 0,5 + 0,42 ; anciennes valeurs (v1–v3, `config_doodle_bottega_rouge.json`) : ×1,22, 0,22, 0,35 + 0,3. Le moteur n'a pas de défaut : tout vient de la config. Pensé pour la compression TikTok ; non testé après vraie compression.
- Animation « sur les doubles » : le trait du texte « bout » à 12,5 i/s (déformation lisse aléatoire), l'encre s'efface en 0,18 s.

## Pièges rencontrés
- Texte coupé en haut de l'écran : le placement borne désormais le patch à 60 px des bords ; `th` (hauteur du texte) est retourné par `doodle.texte`.
- Plan trop court → pas d'écho (durée réduite ≥ 8 images, sinon ignoré).
- Bleu sur plans sombres : illisible ; un liseré clair serait nécessaire. Jaune moutarde/indien : lisibles partout mais moins « street » que le rouge (choix de l'auteur : rouge).
- Détection de visage OpenCV indisponible dans le venv (`cv2.CascadeClassifier` absent) : le hook visage utilisait des coordonnées relevées à la main (`hook_visage`).
- `fetch.py` découpe en gardant l'audio d'origine ; ne pas accélérer ni renforcer les basses pour ce style.
- Couleur par artiste, liseré clair, boucle (1re = dernière image) : **non faits**.

## Styles pixel et basse boostée (clip 17 Jeune Morty « Loli Rock », 13/11/2026)
- `styles` accepte `pixel_nb` (noir et blanc 4 niveaux, trame de Bayer) et `pixel_couleur` (5 niveaux par canal) en plus de `brut` ; clés optionnelles `pixel_larg` (120), `pixel_gamma` (0,7), `pixel_niv_nb`, `pixel_niv_couleur`. Pas de netteté ni d'étalonnage sur ces plans. Config : `exemples/config_doodle_morty.json` (graine 3 : 0 chevauchement ; les graines 11, 17, 29 en laissaient 1).
- Audio sans clip : `scripts/mix/boost_basse.py <stems> <sortie.wav> 12` (basse < 140 Hz +12 dB, limiteur, crête 0,72) ; le clip.mp4 de `work/morty` = images « Deuniers » + cet audio. Paroles collées par l'auteur, calées par Whisper (`align2.py`), deux vers recalés à la main sur l'énergie de la voix.
